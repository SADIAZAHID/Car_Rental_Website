# DriveNow

DriveNow is a Car Rental Management System web application. It features a sleek, asphalt-and-headlight themed interface suitable for modern drivers looking to hit the road.

## Features Implemented
- **Homepage**: Hero banner, route line accents, and featured fleet display.
- **Car Listing (Fleet)**: Explore the bundled fleet dataset with mock functionality.
- **Dark/Light Mode**: Persisted local preference leveraging React Context.
- **Authentication**: Simulated login for users/admins (persisted in context).
- **Responsive Design**: Adjusts efficiently from desktop to tablet and mobile.

## Tech Stack
- Frontend: React 18/19 with Vite, React Router v6, Context API, and Plain CSS.
- Persistence: Browser `localStorage`.
